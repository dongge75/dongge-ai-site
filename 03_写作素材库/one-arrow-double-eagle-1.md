# 复盘 = 看有多少事（实用工具）

> **一句话**：**复盘是实用工具，是给自己看的，是看有多少事**（v11 立）—— **不是营销工具，不是给读者看的，不是为了流量**。
> **来源**：2026-10-17 东哥 1：「关于句池 B，"以为做出来就有人看"，类似这些内容，我写这些东西不是为了让别人看，而是为了复盘，看有多少事情。千万不要突出是为了让别人看的，我们是做实用工具的，是吧？」

## 核心规则（v11 立）

| 维度 | 复盘 = | 复盘 ≠ |
|---|---|---|
| **导向** | **看有多少事**（**盘点**）| 为流量 / 为营销 |
| **主体** | **自己**（东哥 1）| 读者 |
| **目的** | **实用工具**（**梳理自己**）| 营销工具 |
| **写作时想** | "我做了多少事" | "读者想看什么" |
| **写完时想** | "我清楚了" | "读者会转发吗" |

## 通用句池 B v11 → v12 的演化

### v11 之前的错

v11 之前我把通用句池 B 写成"为读者看"导向，**3 个变体都有"以为做出来就有人看"、"以为要建账号才有人看"、"以为用得越复杂越好"等"为别人看"的表述**。

### 东哥 1 v11 纠偏

> 「**我写这些东西不是为了让别人看，而是为了复盘，看有多少事情**」

**关键转变**：
- ❌ v10 "以为做出来就有人看" → ✅ v11/v12 删
- ❌ v10 "以为要建账号才有人看" → ✅ v11/v12 删
- ❌ v10 "以为用得越复杂越好" → ✅ v11/v12 删（不是好不好的问题）
- ✅ v11/v12 加 "复盘的时候才发现，原来做了这么多事"
- ✅ v11/v12 加 "整理成素材才发现，普通人都绕不开"

### v12 润色（用短语）

> v11 → v12：把"认知坑 / 复盘时回头看"等抽象词改为"想错了 / 拉倒"等大白话
> v12 3 个变体：3-7 字短语为主

## 4 段"踩坑"自检清单（v10 + v11 + v12 综合）

1. □ 这坑普通人看得懂吗？看不懂 = 改
2. □ 这坑里有没有"代码 / API / token / 脚本"？有 = 删
3. □ 坑 1 的"怎么错的"是不是和"东哥 1 和我讨论过要改的"一致？一致 = 真实
4. □ **这坑是不是"为了别人看"的？** 是 = 删（**v11 加**）
5. □ **这坑能不能帮我"复盘时发现做了多少事"？** 能 = 留，**不能 = 改**（**v11 加**）
6. □ **这个坑的描述是不是短语（≤ 10 字）？** 不是 = 改（**v12 加**）
