## 📐 8 条提炼规则（最终版）

### 必写 6 项

**1. 要脱敏**
- 摘要式，不暴露原文太细节
- 写「建立了 80% 以上的重复咨询归资料库」，不写「把公司所有制度手册全灌进 WorkBuddy」

**2. 讲作者背景**
- 身份/职业（酒店前厅经理、0 代码 HR 牛马人、广州三娃妈妈、70 后大叔）
- 原始起点（回家带娃、5 个多月、每天 1.5 小时）

**3. 做了什么方向**
- 一句话方向（FDE 服务、AI 带货、公众号标题、资料官复盘）
- 不展开方法论清单

**4. 用了多长时间**
- 时间长度（5 个多月、半年、一周、10 月）

**5. 拿到了什么结果**
- 数字结果（GMV 47w+、服务 16 家企业、播放 249 万、3 文件 0 依赖）
- 状态变化（从学员到教练、业务明显增长、文章点击率提升）

**6. 是否有反馈**
- 自己用了方法后效果（半年从 0 收入做到 20w+）— 可加
- 圈友用了方法后效果（**原文有才加，不能杜撰**）
- 例：金句 2「有收获的点点小赞，希望更多的人用起来」→ 写「有收获的圈友都点了赞」

### 严禁 1 项

**7. 不写具体步骤、不写如何做的、不能泄露谜底**
- ❌「4 步法：用工具抓 SOP 手册；找高手；搜行动手册；用帖子补充」→ ✅「写了一个 4 步法，新手照着做就能入门」
- ❌「3 条核心感悟：聚焦比铺开；不是每个机会都适合；综合评价资源能力后全力去做」→ ✅「2026 年决定做减法，业务明显增长」
- ❌「6 维筛选公式：大人群 + 高频场景 + 强观点 + 认知冲突 + 信息增量 + 反复验证」→ ✅「总结了一个筛选公式，能快速判断一个选题能不能爆」
- ❌ 工具名（WorkBuddy / CLI / Codex / 飞书 / Obsidian / 公众号自动化管线）
- ❌ 159 个数字（→「159 问生成」动作描述）

### 文风 1 项

**8. 用大白话去总结提炼**
- 写「业务明显增长」，不写「业务实现显著跃升」
- 写「让老板更愿意加码配合」，不写「显著提升了客户配合意愿」

## 💡 5 个写作素材（公众号可成文）

### 素材 1：「AI 写内容最危险的不是 AI 味，是『合理推测』」
- **踩坑实录**：第 7 版加「多个圈友用了反馈很好」被东哥抓出
- **3 个隐形特征**：数字看着真实 + 语气像作者 + 难以反查
- **解法**：写每条都问「原文有这句吗？」+ 圈友反馈原文标 🔍 出处

### 素材 2：「个人 IP 站不写工具名 = 不给竞争对手免费广告」
- **踩坑实录**：第 1 版照抄「WorkBuddy / CLI / Codex / 飞书 / Obsidian」
- **本质**：读者看到工具名 = 知道是哪个产品 = 跑去搜 = 跳过你的页面
- **解法**：工具名黑名单 + 改成「用 AI」「用工具」「搭了一套系统」

### 素材 3：「8 条规则写出 100% 真实的圈友推荐」
- **8 条规则**：脱敏/背景/方向/时间/结果/反馈/严禁/大白话
- **跨产品复用**：公众号圈友复盘 / 大 V 拆解 / 同行访谈 / 用户故事都能直接套
- **1 次提炼、跨 N 个场景用**的资产

### 素材 4：「为什么好的内容一定改了 7 遍？」
- **踩坑实录**：东哥给 7 次反馈才有完整 8 条规则
- **本质**：用户描述需求时不完整，迭代是必须成本
- **解法**：写作服务交付 = 至少 3 版起步（初稿 + 1 轮反馈 + 1 轮定稿）

### 素材 5：「AI 协作的跨对话知识传递：Memory 的 2 层存储法」
- **踩坑实录**：东哥问「是否写入了底层逻辑」，我确认后才同意改文件
- **本质**：写进 1 个 memory ≠ 跨对话生效
- **解法**：关键规则 = 双层存储（铁律区 + 详细 memory）
