# 通用句池 A + B v12 完整版

> **一句话**：**通用句池 A**（身份背景"我有什么基础"）+ **通用句池 B v12**（踩坑段"通用句池 B"）= 模板 F 1 段 + 4 段的**固定复用文案池**，**每次写换 1 句**。
> **来源**：2026-10-17 东哥 1：
> 1. 「类似的话，你可以帮我总结一到两句，每次写的时候都要稍微换一下」（**A 句池，v10 立**）
> 2. 「v11，你再润色一下，帮忙优化一下句子，用短语」（**B 句池 v12，v12 定稿**）

## 通用句池 A（**身份背景段"我有什么基础"**）

**触发位置**：模板 F 1 段"身份背景"

**使用规则**：
- 每次写新素材时，**从变体池随机选 1 句**（**不每次都写新的**）
- 写完看一遍："这句话是不是读起来和上篇一样？" → 是 = 换变体
- **不写新的**，**不重复**

### 变体池（v10 立 + v11 自检过）

| 变体 | 完整句 | 备注 |
|---|---|---|
| 1 | 我加入破局快一年了，在里面参加了很多关于 AI 的训练营，学会了 AI 的使用方法，然后把它应用到具体的工作和副业的业务场景中。 | v10 第一版 |
| 2 | 51 岁的我加入破局近一年，通过 AI 训练营学会了用 AI 解决具体工作和副业中的真实问题。 | v10 第二版 |
| 3 | （待东哥 1 补）| — |

> 自检：3 个变体都按 [[content-style]] 铁律"大白话 + 少用双引号 + 不堆 AI 词 + 数字要硬 + 每段一句 + 第一人称"润色过

## 通用句池 B v12（**踩坑段"通用句池 B"**）

**触发位置**：模板 F 4 段"踩了哪些坑"

**使用规则**：
- 每次写新素材时，**从变体池随机选 1 句**（**不每次都写新的**）
- 写法 = **3-7 字短语**（**v12 立的**）
- 导向 = **复盘 = 看有多少事**（**v11 立的**）
- 定位 = **实用工具**（**v11 立的**）
- **不为别人看**（**v11 立的**）
- **不预设清单**（**v10 立的**）

### 变体池（v12 定稿）

| 变体 | 类型 | 完整句 | 短语拆解 |
|---|---|---|---|
| 1 | **最简版** | 我踩的坑都不深奥：一开始以为要会写代码、以为只能搞大项目、以为跑一次就完事。其实都是新手绕不开的常规错。 | 以为要会写代码 / 以为只能搞大项目 / 以为跑一次就完事 |
| 2 | **复盘导向版** | 回过头数一数，坑都不深奥：以为 AI 离我很远、以为要花大把时间学、以为试一次不行就拉倒。复盘的时候才发现，原来做了这么多事。 | 以为 AI 离我很远 / 以为要花大把时间学 / 以为试一次不行就拉倒 / 复盘的时候才发现 / 原来做了这么多事 |
| 3 | **实用工具导向版** | 这些坑没技术含量，就是想错了：以为很难、以为一次性、以为不用记。后来整理成素材才发现，普通人都绕不开。 | 以为很难 / 以为一次性 / 以为不用记 / 整理成素材才发现 / 普通人都绕不开 |

### 4 段自检清单（v10 + v11 + v12 综合）

```
- □ 这坑普通人看得懂吗？看不懂 = 改
- □ 这坑里有没有"代码 / API / token / 脚本"？有 = 删
- □ 坑 1 的"怎么错的"是不是和"东哥 1 和我讨论过要改的"一致？一致 = 真实
- □ 这坑是不是"为了别人看"的？ 是 = 删（v11 加）
- □ 这坑能不能帮我"复盘时发现做了多少事"？ 能 = 留，不能 = 改（v11 加）
- □ 这个坑的描述是不是短语（≤ 10 字）？ 不是 = 改（v12 加）
```

## v10 → v11 → v12 的演化

| 版本 | 核心变化 | 触发 |
|---|---|---|
| v10 | 通用句池 B 第一版（**3 个变体**）| 东哥 1 v10 立"通用句池 B" |
| v11 | 删"为别人看"导向 + 加"复盘=看有多少事"导向 + 加 2 条自检 | 东哥 1 v11 纠偏"我写这些东西不是为了让别人看" |
