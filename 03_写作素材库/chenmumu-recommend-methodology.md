## 4 块结构（最核心，写每篇解读的格式）

每篇精华帖解读 = **4 块**：

```
一、成绩板    作者做项目拿到的成绩（赚多少/播放/涨粉）
             只放原文里有的数字。
             不放阅读量/点赞/锚点。

二、脱敏摘要  80-140 字：作者背景 + 做了什么方向 +
             用了多长时间 + 拿到什么结果。
             不出现：工具名、步骤、参数、渠道。

三、解决了什么问题
             4-6 条，每条以问号结尾。
             只提问，不给答案。
             留悬念 → 引导看原帖。

四、原作者原话
             2-3 句，逐字摘，一个字不改。
             只选观点句，不选操作步骤。
```

**4 块下面**挂一句"答案在原帖里" → 引流到原帖/领卡。

### 4 块结构的合规逻辑（陈木木 line 187-189）

- **合规** → 不暴露完整方案
- **留悬念** → 让读者想看原帖
- **保护原作者** → 不抄操作步骤

## 6 步法（整个种草页 0-1 流程）

1. **需求说给 AI** → 让 AI 先出方案再执行
2. **先挂 60 分版本** → **"先完成再完美"**（第一版挂出去当天就有人领卡）
3. **接入生财 MCP** → 自动拉精华帖（破局版 = 接入破局 CLI）
4. **把"怎么写解读"写成说明书** → 喂给 AI（**就是 4 块结构**）
5. **UI 照官网风格做** → 用户跳转无适应期
6. **让网页自己定时更新** → 拉→去重→选→写→查→上传→通知飞书

## 去 AI 味 3 步（line 137）

```
1、自己口述一遍内容
2、找一篇同类型的文章（陈木木找的是小鱼老师）
3、让 AI "套壳" 改写
```

**AI 味能去掉 90%**。

## AI 自动更新流程（line 235-251）

```
一、拉精华榜（按点赞收藏排序）
二、跟已收录的去重
三、按标准选一篇，拉全文
四、按 4 块结构写解读
五、下载作者头像和封面
六、跑检查脚本（问号结尾 / 无半角标点 / 字段齐）
七、上传，页面重新生成
八、飞书通知"今天收录了哪篇"
```

**出错也通知飞书**；当天没合格新帖 → 记"今天跳过，明天再试"。

## Why

陈木木的"4 块结构"是精华帖解读的**最稳模板**（生财官方认可，亦仁审过）。用户的 /recommend/paiju 当前 cases section 是 whenreset 模板的假数据，**未来接入破局 CLI 时必须按这个 4 块结构**自动更新，才能既真实又合规。

## How to apply

写任何"破局精华帖解读"时，**严格按 4 块结构**：成绩板（原文数字）→ 脱敏摘要（80-140 字，无工具名）→ 问题清单（4-6 条问号）→ 原作者原话（2-3 句逐字）。4 块下面必须挂"答案在原帖里"+"立即领卡"引导。
